# Ask Alex API

Backend for the Ask Alex chatbot on https://rokskrinjar.si/ah-distilled/ask.html.
A single Vercel serverless function (`api/ask.js`) that sends the question, a short history and a compact version of the AH distilled knowledge base (`kb.js`, generated) to the Anthropic Messages API, with prompt caching on the knowledge base.

`kb.js` is generated by `python3 ah-distilled/kb/build.py`. Do not edit it by hand.

## Deploy (once)

1. On vercel.com: **Add New → Project → Import** `rokskrinjar/rokskrinjar_si`.
2. **Root Directory:** `ask-alex-api`. Framework preset: **Other**. Deploy.
3. **Settings → Environment Variables:** add `ANTHROPIC_API_KEY` (from console.anthropic.com), then **Redeploy**.
4. In the Anthropic Console, set a **monthly spend limit** for this key. That is the real cost guard for a public chatbot.
5. Put the deployed URL in `ah-distilled/assets/ask-config.js`:
   `window.ASK_ALEX_API = "https://<your-project>.vercel.app/api/ask";` and push.

Vercel only rebuilds when files in `ask-alex-api/` change (`ignoreCommand` in `vercel.json`).

## Optional environment variables

| Variable | Default | Meaning |
|---|---|---|
| `ASK_ALEX_MODEL` | `claude-sonnet-5-5` | Model id, e.g. `claude-haiku-5-5` for lower cost |
| `ASK_ALEX_PER_IP_PER_HOUR` | `20` | Questions per IP per hour (per server instance, best effort) |
| `ASK_ALEX_ORIGINS` | rokskrinjar.si, www, localhost:8000 | Allowed browser origins (CORS) |

## Guards

Origin check (CORS), per-IP hourly limit, message length and history limits, `max_tokens` 600, and the spend limit on the API key.
