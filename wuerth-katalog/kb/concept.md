# THE CONCEPT: Račko (what this site is)

- "Račko" is a concept by Rok Skrinjar. It turns one public Würth Slovenia PDF catalogue of tool trolleys and foam tool sets ("Izberite si voziček z orodjem, katerega si zaslužite", 2021, 60 pages, without prices) into a smart online catalogue, and shows what that gives the sales team. The concept is not affiliated with Würth d.o.o. or the Würth Group. Nothing can be ordered here, and inquiries sent from the page stay in the visitor's own browser.
- Pages:
  - index.html (Katalog): search that understands how the trade talks, sizes (SW, TX, imbus), limits (width, load) and article codes; a picker by type of work; trolley cards with drawings to scale; assortments; foam sets; details; side-by-side comparison; the chat with Račko.
  - predali.html (Sestavi predale): a drawer configurator built on the module rule on page 25 of the catalogue. Pick a trolley, add foam sets, see what fits and what stays free; export the codes, send an inquiry.
  - prodaja.html (Pogled prodaje): the inquiry inbox; a real analysis of the 12 assortments (which sets they reuse most, how many drawers stay empty, a simple rule that suggests what to add); the visitor's own searches as a live signal; the measures a pilot would track.
  - priloznosti.html (Možnosti, "Zakaj ta koncept"): 12 options for sales analytics and AI, ranked by value and feasibility, a 90-day plan, what already exists in the Würth Group, what the author would not do, responsible use.
  - podatki.html (Od PDF-ja do podatkov): how the PDF became checked data, what AI did and may not do, the sums of pieces per assortment, and the spots in the catalogue to reconcile.
- What is real and what is not: all product facts come from the PDF. The analysis on prodaja.html uses only the catalogue, not sales data: it shows which sets are in assortments, not which ones sell. The two sample inquiries are fictional and marked. Value and feasibility scores are the author's judgement before seeing any data.
- Why this concept: the question the author asks first is who the customers are and what they need. With about EUR 17 million revenue and more than 13,000 customers, the average is around EUR 1,300 a year per customer, so not every customer can or should get the same path. The Group already builds many AI tools; the local lever is clean data, local questions and getting the tools to the reps.
- How a real rollout would work: start with one category where customers ask the most; log searches without results and fix the dictionary and missing attributes monthly; add the adviser limited to product data; measure against a control period (searches without results, conversion, calls about choosing a product, inquiries with codes); test answers weekly on a set of real questions; extend only if the numbers hold.
- How it was built: the PDF was read in text and image form, the data written to one JSON file with a source page on every record, and a script checks every code and measure against the PDF and sums the pieces. Foam size is not written anywhere in the catalogue: it was measured from the page geometry. The search and the comparison run in the browser without a model. The chat is limited to the catalogue, and the page shows a product card only if the code exists in the data.
